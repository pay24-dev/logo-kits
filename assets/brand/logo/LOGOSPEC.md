# LOGO-SPEC.md — Pay24.now logo construction & usage

- **Brand string:** `Pay24.now` (exact spelling and capitalization).
- **ID:** BRD-LOGO-001, proposed logo lockup construction derived from verified user reference.
- **Observed mark:** 22 white radial ring segments, no stroke, one forked green cap at top, filled interior is background/transparent. The negative-space V notch is distinctive; preserve it.
- **Observed colors:** charcoal `#121212`, white `#FAFAFA`, green `#3ECF8E`. These describe the reference, not comprehensive theme status colors.
- **SVG viewBox:** symbol uses 200×200 coordinate grid; paths constructed for crisp vector rendering at arbitrary size.
- **Typography:** Proposed outlined Inter Display Bold glyphs; `Pay24` and `.now` visually distinguished by semantic color. SVGs contain path geometry, not editable text. Recreate with the same outlined source when changing letters.
- **Required lockups:** horizontal dark/light, stacked dark/light, text-only dark/light, icon-only, mono light/dark and app tile.
- **Avoid:** flip/mirror or rotate the mark, remove V notch, add many brand colors, replace segments with a loading animation, distort aspect ratio, use a light mark over light UI, or hardcode a source site's identity.
- **Caution:** Green is a brand accent, NOT an automatic success signal for payments or compliance.
- **Allowed variations:** single-color reproductions, inverse contrast, explicit light-surface/dark-surface variants, size exports using original geometry.
- **Approval needed:** final wordmark letterforms/kerning, web favicon tests at 16px, alternate print profiles and legal clearance.
- **Acceptance tests:** files parse as XML; no external image/font dependencies; original raster preserved; forked top mark present; correct brand name; dark/light variants work; minimum-size legibility manually reviewed before production.
