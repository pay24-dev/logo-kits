# Pay24.now — Wordmark and typography

## Identity and provenance
The newer `v2` wordmark is custom stylized lettering supplied as SVG outlines, not a font package. The exact underlying font family **cannot be verified** from the accessible source material. Earlier documentation identified **Inter Display Bold** as part of the previous design proposal; it does not establish the font of the newer selected lettering.

The earlier documentation refers to a selected AI-generated lettering screenshot, but that screenshot is not among the tracked Git files reviewed for this migration. Retain that uncertainty rather than claiming full source provenance.

## Distribution and usage
- Newer wordmarks: [v2 on dark](../assets/v2/svg/pay24-wordmark-on-dark.svg) and [v2 on light](../assets/v2/svg/pay24-wordmark-on-light.svg).
- Horizontal and stacked lockups: [full catalog](../assets/CATALOG.md).
- Do not substitute a system font for the outlined logo or alter the capitalization, glyph counters, dot position or spacing without issuing a coherent new design version.
- Do not use these decorative outlines to set interface body copy; choose a suitable accessible UI font for product text.
- Both earlier `v1` and newer `v2` are retained to avoid mixing distinct renderings or losing historical alternatives.
- No font binaries are required to use the SVG assets.

Legal/trademark approval and production browser accessibility remain separate validation activities.
